# Nerd Fonts Icon Reference

Quick reference for icons available with Nerd Fonts installation.

## Installation

1. Download from https://nerdfonts.com/font-downloads
2. Install font (JetBrains Mono, Hack, Fira Code recommended)
3. Set terminal to use the Nerd Font

## Using in Code

```go
// Go
const (
    FolderIcon    = "\uf115"
    GitBranchIcon = "\ufb02"
    SuccessIcon  = "\uf00c"
)
```

```javascript
// Node.js
const icons = {
    folder: '\uf115',
    gitBranch: '\ufb02',
    check: '\uf00c',
};
```
