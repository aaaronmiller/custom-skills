# Living Document Workbench

Run locally:

```bash
npm run validate
npm run dev
```

Open the printed local address. The starter has no runtime dependencies and makes no network requests.

Canonical content lives in `public/content/` and `public/data/`. Browser edits are local overlays until exported as a change request.
