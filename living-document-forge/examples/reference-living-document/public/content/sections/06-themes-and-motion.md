## Obsidian Editorial Workbench

The default theme uses blue-black surfaces, mineral teal for primary interaction, and amber for annotations and unresolved attention. Serif headings give long-form material an editorial voice; interface text remains compact and neutral.

The direction avoids the visual shorthand that makes many AI interfaces indistinguishable: purple gradients, neon grids, glass everywhere, glowing brains, and rounded containers around every sentence.

## Complete theme choices

The reference includes:

- `system`, which follows the operating-system color preference;
- `obsidian`, the default dark research surface;
- `graphite`, a near-monochrome dark alternative;
- `paper`, a warm light editorial theme;
- `high-contrast`, with strong focus and status visibility.

Every component consumes semantic tokens. A theme is complete only when forms, code, selections, dialogs, statuses, and focus rings remain coherent.

## Tactility without spectacle

Buttons respond to hover and press. Navigation state has a moving marker. Dialogs settle into place. Theme changes may use a progressive view transition when available.

None of these effects is required for comprehension. Reduced motion removes nonessential movement while preserving instant state changes. The interface does not animate every section on scroll, use parallax, or move the reading position for decoration.
