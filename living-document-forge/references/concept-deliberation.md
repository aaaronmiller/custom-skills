# Concept deliberation protocol

Use this reference when the document is exploratory, when the user is still deciding what the project is, or when a request asks for feasibility, quality, content, tensions, extensions, or alternative implementations rather than a fixed specification.

## Preserve the conversation

A living concept canvas is not a requirements warehouse. Its job is to retain the strongest current formulation of the idea while keeping unresolved questions visible and addressable. A model-authored revision should improve the conversation, not end it prematurely.

Classify statements before placing them:

- **Founding premise:** a proposition the project currently depends on.
- **Design hypothesis:** a plausible mechanism that still needs a proof.
- **Feasibility claim:** what can be built now, what needs major engineering, and what remains research-grade.
- **Quality doctrine:** what must be true for the project to avoid becoming shallow.
- **Content opportunity:** an extension that deepens the central fantasy.
- **Risk:** a failure mode with a cause and consequence.
- **Experiment:** a bounded prototype that can validate or falsify a claim.
- **Decision:** an approved direction with recorded rationale.
- **Refusal:** an explicitly rejected direction or boundary.
- **Open question:** a live uncertainty that should not be disguised as a decision.

Do not translate every vivid example into abstract product terminology. Concrete images such as a carved wheel, a damaged lens, a mural appearing on a village wall, or a musician heard from another room often carry more design information than a generic label.

## Four-layer model

For Culture Foundry and similar concepts, test every major addition against four cooperating layers:

1. **Settlement layer:** resources, places, institutions, events, labor, and history.
2. **Artist layer:** individual memory, taste, capability, relationships, and development.
3. **Mechanism layer:** reusable creative process, controls, delegation, memory, and medium adapters.
4. **Studio layer:** the immediate assembly, generation, review, and revision of artifacts.

A feature is suspect when it only decorates one layer and has no consequence elsewhere. A new pigment should affect resource collection, artist practice, mechanism controls, visual output, criticism, and later cultural memory. A new medium should create new labor, institutions, device forms, risks, and export possibilities.

## Feasibility writing

Do not answer feasibility with a vague yes or no. Separate:

- feasible in a small prototype now;
- feasible with substantial production engineering;
- dependent on model quality, cost, or provider stability;
- research-grade and requiring experiments;
- conceptually harmful even if technically easy.

Tie each claim to a proof. For example, long-term style evolution is not validated by generating five similar images. It requires a lineage test across many artifacts, changing artists, events, materials, and rival influences.

## Extension discipline

An extension belongs when it strengthens the same central loop. Prefer additions that create new causes, choices, feedback, or consequences. Reject breadth that merely adds another file type or model endpoint.

Good extension questions:

- What new player decision appears?
- What simulation state causes the output to change?
- What new institution, artist behavior, or mechanism module is required?
- How does the artifact return consequences to the world?
- What can be tested independently?

Weak extension questions:

- Can the system also generate another medium?
- Can it have more themes?
- Can it add a marketplace before provenance and rights exist?
- Can the model decide everything automatically?

## Contradictions

When two strong directions conflict, preserve both and name the tension. Examples include autonomy versus authorship, abundance versus attention, cultural coherence versus novelty, historical grounding versus fantastic invention, and physical illusion versus interface accessibility.

Convert the conflict into one of:

- a selectable mode;
- an institutional difference;
- a progression change;
- a prototype comparison;
- an explicit proposal;
- a refusal if one side breaks the project.

Do not smooth contradictions into empty language such as “balance both.” State what would be traded and how the game could expose the tradeoff.

## Section creation

Create a new section only when the topic has its own durable question, vocabulary, and future decision surface. A new section should answer:

- why the topic matters;
- how it operates;
- what it changes elsewhere;
- what can fail;
- what remains undecided.

Use references and annotations rather than duplicating neighboring sections. Keep titles argumentative, not merely categorical. “The council must judge without pretending taste is objective” is stronger than “Evaluation System.”
