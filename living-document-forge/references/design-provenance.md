# Design provenance

The 1.0 interface direction was developed using the user-supplied `frontend-design-masterclass.SKILL` as a design review source.

Applied principles:

- identify product type and reading context before choosing an aesthetic;
- avoid card saturation and generic AI visual tropes;
- construct independent light and dark themes from semantic tokens;
- provide a theme selector and native color-scheme alignment;
- define motion durations and easing as tokens;
- use motion only for feedback, orientation, or restrained delight;
- provide explicit and operating-system reduced-motion behavior;
- design every control state;
- verify responsive layout, focus visibility, and high contrast.

The resulting implementation is original to this package. The attached design skill itself is not redistributed.
