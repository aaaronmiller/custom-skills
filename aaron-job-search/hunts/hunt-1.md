# Hunt 1 — Wellfound Small Startups Seattle (2–50) + Built In Seattle — 2026-08-20

## Target

Hunt 1 targets Wellfound (AngelList Talent) Seattle small startups (2–50 employees) plus Built In Seattle startup listings and supplemental TopStartups.io Seattle pages. Goal: 100 unique Seattle-area jobs with a bias to small companies where Aaron's cross-domain edge (AI agent orchestration 300M tokens, full-stack Svelte/TS, WSL2 systems tuning, hardware repair, semiconductor thesis, knowledge systems) is a differentiator, not commodity. All roles considered including agentic engineering; tech-adjacent ops roles included then down-ranked.

## Rationale

Wellfound is S-tier for Aaron: salary bands visible, 1-click apply, AI-heavy small teams. Built In Seattle catches Seattle companies Wellfound misses (including mid-size). Angle 1 is the highest expected density for Seattle-small-startup signal. Aaron's Independent AI Implementation Specialist identity (60–80% cost reduction, 99.9% uptime, 20+ platforms) maps directly to AI infra / platform / solutions roles that dominate small AI startups. Location filter: Seattle proper preferred; remote US+LatAm allowed only if Seattle-listed.

## Things Learned From Prior Hunts

- Hunt 1 is the baseline — no prior hunts.
- Finding: Wellfound JS-heavy SPA requires login for company-size filter; first page SSR renders ~10 cards (26 jobs at 2–50 after dedupe from 452 total Seattle jobs).
- Finding: Built In Seattle startup size filter is client-side JS and unreliable — manual size check needed.
- Finding: Supplemental sources (GeekWire 200 blocked by Cloudflare WAF, YC WaaS JS SPA, Otta auth wall, Indeed WAF) yield 0 additional 2–50 employee jobs — that market lives exclusively on Wellfound. The 181 supplemental jobs are 101+ employee companies.
