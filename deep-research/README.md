# Deep Research Skill (Certified V2.0)

> **"The Gold Standard for Information Gathering"**

A sophisticated, multi-level research agent designed to perform exhaustive investigation, decomposition, and synthesis of complex topics. Unlike generic search tools, this skill enforces strict **Source Evaluation** and **Dialectical Synthesis** protocols to ensure high-accuracy engineering output.

## Core Features
1.  **Operator-Driven Search**: Uses specialized Google Dorks (`filetype:pdf`, `site:arxiv.org`) to pierce SEO spam.
2.  **Mandatory Credit Scoring**: Every source is graded on a [Bias] and [Credibility] matrix.
3.  **Conflict Resolution**: Uses Dialectical Synthesis (Thesis-Antithesis-Synthesis) to resolve data conflicts.
4.  **Infinite Context**: Uses "File Rotation" to handle massive research sessions.

## The Brain (Resources)
This skill is backed by a knowledge library in `resources/`:
