# CASS Report Patterns — The 15 Report Types

> Progressive-disclosure resource. The prompt-mine SKILL.md references this file
> when a report is requested. An agent SHALL read this file when any `report:<type>`
> action is triggered.

Every report follows a standard shell:

```
┌─────────────────────────────────────────────┐
│ REPORT: <Name>                              │
│ PERIOD: <time range>                        │
│ GENERATED: <timestamp>                      │
│ SOURCES: <N> sessions across <M> agents     │
├─────────────────────────────────────────────┤
│                                              │
│ <structured content>                         │
│                                              │
│ RECOMMENDED ACTIONS:                         │
│ • <action>                                   │
│                                              │
│ GENERATED BY: prompt-mine v<version>         │
└─────────────────────────────────────────────┘
```

---

## 1. Daily Brief
**Purpose:** What happened today across all projects.
**Frequency:** On-demand or end-of-day.
**Commands:**
```bash
cass timeline --today --json
cass search "" --robot --today --aggregate agent,workspace --limit 1
```
**Output:** Sessions today grouped by agent, notable projects touched, summary line.

---

## 2. Weekly Digest
**Purpose:** Week-level summary for all monitored projects.
**Frequency:** On-demand or end-of-week.
**Commands:**
```bash
cass timeline --days 7 --json
cass search "" --robot --days 7 --aggregate agent,workspace --limit 1
```
**Output:** Sessions by day, per-agent breakdown, top workspaces, week-over-week change (if prior week data available).

---

## 3. Monthly Review
**Purpose:** Month-level aggregation with trends and distribution.
**Frequency:** On-demand or end-of-month.
**Commands:**
```bash
cass timeline --days 30 --json
cass search "" --robot --days 30 --aggregate agent,workspace,date --limit 1
```
**Output:** Monthly session counts, agent distribution pie, workspace activity, trend arrows.

---

## 4. Sprint Retrospective
**Purpose:** All activity since a given date with highlights and blockers.
**Frequency:** On-demand.
**Commands:**
```bash
cass timeline --since YYYY-MM-DD --json
cass search "error|blocker|issue" --robot --since YYYY-MM-DD --limit 20
cass search "TODO|FIXME" --robot --since YYYY-MM-DD --limit 20
```
**Output:** Timeline of sessions, notable issues found, TODOs created, overall narrative.

---

## 5. Project Deep Dive
**Purpose:** Complete session history for one project.
**Frequency:** On-demand.
**Commands:**
```bash
cass search "" --robot --workspace /path/to/project --limit 100
cass sessions --workspace /path/to/project --json --limit 50
cass search "" --robot --workspace /path/to/project --aggregate agent,date
```
**Output:** All sessions for project grouped by agent, timeline, session count, agent mix, recurring topics.

---

## 6. Cross-Project Dashboard
**Purpose:** Every project with session counts, agents used, last activity.
**Frequency:** On-demand or weekly.
**Commands:**
```bash
cass search "" --robot --aggregate workspace --limit 1
cass sessions --json --limit 50
```
**Output:** Table of projects with session count, agent list, last activity date, staleness level.

---

## 7. Stale Projects Report
**Purpose:** Projects not touched in N days.
**Frequency:** On-demand.
**Commands:**
```bash
cass search "" --robot --days 14 --aggregate workspace --limit 1
# Cross-reference with known workspaces to find gaps
```
**Output:** List of projects with no sessions in N days, sorted by staleness.

---

## 8. Agent Utilization Report
**Purpose:** How much each agent was used, on which projects.
**Frequency:** On-demand.
**Commands:**
```bash
cass stats --json
cass search "" --robot --days 30 --aggregate agent,workspace --limit 1
```
**Output:** Per-agent: session count, project list, percentage of total, token usage trend.

---

## 9. Agent Cross-Reference
**Purpose:** Which projects used multiple agents (handoff detection).
**Frequency:** On-demand.
**Commands:**
```bash
cass search "" --robot --aggregate workspace --limit 100
# Query workspaces with >1 distinct agent
```
**Output:** Projects where 2+ agents were active, when switches happened, handoff context.

---

## 10. Work-in-Progress Report
**Purpose:** Active/incomplete sessions and projects.
**Frequency:** On-demand or daily.
**Commands:**
```bash
cass sessions --current --json
cass search "in progress|wip|ongoing" --robot --limit 20
cass timeline --today --json
```
**Output:** Currently open sessions, recently touched files, projects with recent but unresolved activity.

---

## 11. Outstanding TODOs Report
**Purpose:** All TODO/FIXME/HACK/XXX markers found across sessions.
**Frequency:** On-demand.
**Commands:**
```bash
cass search "TODO|FIXME|HACK|XXX|WORKAROUND" --robot --limit 50 --fields snippet,workspace,agent
```
**Output:** List of technical debt markers, grouped by project, with context snippet and session link.

---

## 12. Error Pattern Report
**Purpose:** Common errors and failures across all projects.
**Frequency:** On-demand.
**Commands:**
```bash
cass search "error|exception|fail|timeout|crash|panic" --robot --limit 50 --fields snippet,workspace,agent
```
**Output:** Error types, frequency per project, recurring patterns, suggested remediation.

---

## 13. Technology Radar
**Purpose:** Technologies, languages, frameworks mentioned across sessions.
**Frequency:** On-demand.
**Commands:**
```bash
cass search "using |implemented |migrated to |upgraded " --robot --limit 50 --fields snippet,workspace
# Synthesize by extracting tech names from snippets
```
**Output:** Technology inventory per project, adoption trends, deprecated tech.

---

## 14. Activity Heatmap
**Purpose:** Daily/weekly activity density over a time period.
**Frequency:** On-demand.
**Commands:**
```bash
cass search "" --robot --days 90 --aggregate date --limit 1
```
**Output:** Day-by-day session counts, busiest days, weekend activity, long gaps.

---

## 15. Learning Summary
**Purpose:** Synthesis of what was built, broke, and learned in a period.
**Frequency:** On-demand or monthly.
**Commands:**
```bash
cass search "" --robot --since YYYY-MM-DD --aggregate workspace --limit 50
cass search "learned|discovered|lesson|finally figured out" --robot --since YYYY-MM-DD --limit 20
cass search "error|fail|bug" --robot --since YYYY-MM-DD --limit 20
```
**Output:** Narrative summary: projects advanced, key discoveries, recurring problems, knowledge gained.

---

## Composition Rule

When the user describes a need not exactly matching one of the 15:

1. Run the closest matching report's CASS commands
2. Add supplementary searches for the specific angle
3. Compose the two result sets into a narrative
