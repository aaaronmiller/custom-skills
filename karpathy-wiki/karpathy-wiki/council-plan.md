_Generated by spec-audit-skill Phase 3. Date: 2026-05-22._

## Recommended Formation

**Parallel Groups** (8 agents, two groups of 4) → Merge Council

| Group | Perspective | Materials | Role |
|-------|-------------|-----------|------|
| **Group A (Internal)** | As-built spec | `spec-as-built.md` + full project codebase awareness | Defend the as-built design philosophy. Surface real constraints that external answers may miss. |
| **Group B (External)** | S-tier answers | `external-answers.md` (user-provided) | Argue for the ideal spec direction from the S-tier model's answers. Push for improvements. |
| **Merge Council** | Both + group outputs | Outputs from both groups + both source docs | Reconcile disagreements. Produce unified `ideal-spec.md` and `task-list.md`. |

## Profile

**V(8, 3, 1)** — Standard profile (8 agents, 3 rounds, 1 web probe between rounds)

## Mode

**REFINE** — comparing two inputs (as-built spec + external answers), producing a synthesized ideal

## Strategy

**BRANCHING** — explore the gap between internal and external perspectives independently before converging. This prevents one perspective from dominating early.

## Execution Plan

1. **Group A deliberates in isolation** — reads spec-as-built.md, constructs internal defense
2. **Group B deliberates in isolation** — reads external-answers.md, constructs ideal push
3. **Both groups produce** a position paper per sub-question (agree/disagree/modify, with rationale)
4. **Merge council** reconciles positions, produces:
   - `ideal-spec.md` — full target spec
   - `task-list.md` — prioritized implementation tasks
